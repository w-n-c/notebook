## What this audit does not claim

It is not exhaustive. It is a snapshot of where the standard visibly bites, taken
by reading the files above, and its purpose is to make the next eleven fixes a
matter of choice rather than discovery. A file with no entry is a file that read
at one level in this pass — not a file guaranteed to be clean forever.
